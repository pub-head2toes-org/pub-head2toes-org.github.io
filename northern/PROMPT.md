# Northern

It is a JS Node app that implements the wrapper around Sqlite3 DB providing a REST API interface for key value pair storage, where:

* HTML POST for URL and JSON payload allows for record creation 
* PUT allows for update
* GET allows for retrieval
* It allows serving data based on the URL path as a key from Sqlite or file system
* It provides the editor and command line interpreter as a HTML, JS and CSS implementation at `src/fs/keyboard.html`
