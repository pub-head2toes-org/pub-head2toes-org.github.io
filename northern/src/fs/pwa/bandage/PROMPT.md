# PWA Bandage

The PWA that implements 25 key piano keys and integrate with webaudio tinysynth to generate the music

## Implementation considerations
* implement as PWA using HTML, JS and CSS
* implement a full screen 25 piano keys
* use this lib for music synth: `https://github.com/g200kg/webaudio-tinysynth`
* reserve the upper third of the screen for future development
