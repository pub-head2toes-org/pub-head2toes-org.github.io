# PWA Pals - Update 10

Focus of this update is to do an exploratory spike for feasibility of following new features

## Explore feasibility

* Utilizing WebRTC to implement conference video call of up to four participants
  * What are limits on peer to peer connections and what would be estimated bandwidth for four participants
  * How would UI be set for smaller screens like phones
* Check implementation options to  introduce encryptions of the video stream in existing video calls (one to one calls)
  * Would it be possible to encrypt the captured video and audio before sending?
  * How intensive computational overhead would it be?
