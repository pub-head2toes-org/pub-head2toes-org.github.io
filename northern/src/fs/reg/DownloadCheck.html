Download check

Finds out why saving an ID Card can hang on some iPhones. Nothing here touches your ID Card or your keys: every test saves a small text file whose name starts with northern-check, which is safe to delete afterwards.

Do the steps in order, then copy or share the report at the bottom.

1. This phone

Look these up in the Settings app. They go into the report.

2. This browser

Read by the page itself.

3. Tests

Run one test at a time. Watch for the “Download?” question and the progress line under the address bar, wait up to a minute, then say what happened. Do not tap Continue or leave the page while a download is running.

A. Save Id Card, no passphrase

What Reg.html did before Update 10: the page clicks a hidden data: link by itself, straight after your tap.

not run

B. Save Id Card, with a passphrase

As A, after the same encryption Reg.html does for a passphrase. The file name has a * in it, as an encrypted ID Card’s does.

not run

C. As B, without the *

Same encryption first, plain file name. If B hangs and C does not, the * is to blame.

not run

D. Click 3 seconds after the tap

The page waits 3 seconds, then clicks. By then Safari may no longer count the click as yours.

not run

E. Tap a real data: link

Like Reg.html’s old “Download Id Card again”: you tap the link itself, nothing is clicked for you.

Run E
not run

F. Tap a real Blob link (text file)

As E, but the file is a Blob marked as plain text instead of a data: URL. Reg.html’s “Download Id Card” since Update 10.

Run F
not run

G. Share sheet › Save to Files

Opens the share sheet with the file, as Reg.html’s “Share / Save to Files” does since Update 10. Choose “Save to Files” and pick On My iPhone. Safari’s downloads are not used at all.

not run

4. Check what reached the phone

Pick the files the tests saved, from Files › Downloads (in iCloud Drive or On My iPhone, wherever step 1 says) or wherever you saved test G. You can pick several at once. A test whose file is found gets a bright border.

5. Report

Copy it, or share it by Messages or Mail. A screenshot of it works too.
