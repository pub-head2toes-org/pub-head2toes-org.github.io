* To allow easy use in devices with touch screens introduce the following:
  * On all pages add the footer as a `div` that will hold `button` elements in the single row on the bottom of the page
  * Buttons to mimic the function of the keys: `Esc`, `Tab`, `Up`, `Down`, `Enter`
  * The purpose is to allow an easy way of touching the buttons with the same effects as pressing the keys
* Add new feature on the Details page
  * If the value of the column that is to be rendered in the line on the details page represents the valid URL then add action on pressing 'Enter' key (of button)
